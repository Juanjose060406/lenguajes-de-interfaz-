Descripción

Este repositorio contiene las prácticas desarrolladas durante la Unidad 2 de Lenguajes de Interfaz. Los programas están escritos en Assembly utilizando MASM x86 de 32 bits y la biblioteca Irvine32.

Cada práctica incluye su archivo fuente ".asm", encabezado de identificación y comentarios que explican las partes principales del programa.

Requisitos

- Windows
- Visual Studio con herramientas MASM de 32 bits
- Biblioteca Irvine32 configurada
