## Requisitos
- Windows.
- Visual Studio con herramientas de C++ y Microsoft Macro Assembler (MASM) de 32 bits.
- Biblioteca Irvine32 correctamente instalada y configurada.

## Indicaciones
- Cada archivo `.asm` corresponde a un programa independiente; compila y ejecuta una práctica a la vez.
- Los archivos fuente incluyen encabezados de identificación y comentarios de apoyo.
- Los programas usan `INCLUDE Irvine32.inc`. Configura las rutas de inclusión y bibliotecas según la ubicación de Irvine32 en tu equipo.
- Revisa y prueba cada práctica en tu entorno antes de entregarla, y confirma que corresponda a las indicaciones específicas del docente.
